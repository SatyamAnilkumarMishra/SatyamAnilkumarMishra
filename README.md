## 🚀 Featured Projects

### 1. [Career Advisor](https://github.com/SatyamAnilkumarMishra/career-advisor)
An AI platform that analyzes resumes, identifies skill gaps, generates learning roadmaps, and matches jobs.
- Combines a FastAPI backend with a Next.js frontend and ChromaDB for document search.
- Includes a custom Model Context Protocol (MCP) server so AI assistants like Claude can use its tools directly.
- **Tech:** Python, FastAPI, Next.js, ChromaDB, LangChain

### 2. [ClaimSense](https://github.com/SatyamAnilkumarMishra/ClaimSense)
An automated insurance claim adjudication system with built-in guardrails against AI hallucinations.
- Uses Databricks (Delta Lake) and a LangGraph state machine to process and audit claims.
- Validates cited policy clauses against actual contracts before generating decisions.
- Tested thoroughly with 50+ automated unit tests.
- **Tech:** Python, Databricks, Delta Lake, LangGraph, FastAPI, Streamlit

### 3. [eval-harness-mcp](https://github.com/SatyamAnilkumarMishra/mcp)
A lightweight Model Context Protocol (MCP) server built with zero external dependencies.
- Built using only Python's standard library to handle raw JSON-RPC 2.0 communication over standard input/output.
- Connects directly to an evaluation harness to benchmark and test LLM models.
- **Tech:** Python (Standard Library only), JSON-RPC 2.0

### 4. [lustre-cli](https://github.com/SatyamAnilkumarMishra/lustre-cli)
A command-line tool that automates setting up distributed storage on Linux.
- Sets up iSCSI network storage and deploys high-performance Lustre filesystems across servers.
- Includes built-in benchmarks to measure read/write speeds and tools to test how the system recovers from network drops.
- **Tech:** Python, Lustre, iSCSI, Linux

### 5. [resilient-file-storage](https://github.com/SatyamAnilkumarMishra/resilient-file-storage)
A fault-tolerant distributed file storage prototype.
- Splits files into chunks, replicates them across multiple storage nodes, and handles automatic failover if a node goes down.
- **Tech:** Node.js, Distributed Storage
